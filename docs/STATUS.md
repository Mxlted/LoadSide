## Local app library, unsigned injection, and widescreen workspace — 2026-10-12

- Added a private signed-export library with an opt-in local HTTP catalog, QR sharing link, downloads, and HTTPS OTA manifests. Sharing exposes only immutable managed copies bound to the signing result's SHA-256, with random per-session routes, bounded clients/requests/timeouts, streamed transfers, and link rotation on restart. Removal preserves the user's exported IPA. Older results without a recorded bundle version are download-only.
- Browser installation requires a user-configured HTTPS reverse proxy and a certificate trusted by the iOS device. No tunnel, external manifest proxy, trust-root installation, or remote signing is performed. Reviewed [SignTools](https://github.com/SignTools/SignTools), [SignTools-CI](https://github.com/SignTools/SignTools-CI), and [Apple's HTTPS distribution requirements](https://support.apple.com/guide/deployment/distribute-proprietary-in-house-apps-depce7cefc4d/web); no upstream source or new runtime dependency was copied.
- Added **Inject only** and `loadside inject`, accepting compatible DEBs/dylibs/frameworks without P12, profiles, or passwords. The engine validates and stages inputs, removes old signatures/profiles, and atomically exports a distinctly unsigned archive. Structural Mach-O checks verify signature-command absence across slices; untrusted filenames cannot turn a failed tool diagnostic into success. Original files remain unchanged. Signature-only entitlements are removed and must be restored through authorized signing.
- Adapted the native workspace to a 1280×720 default with a compact sidebar, fixed source/mode and export controls, independently scrolling input/settings columns, and expandable settings. Updated Activity to distinguish unsigned preparation from verified signing, and added adaptive saved-profile and Help grids. Native UI inspection covered both workflow modes and Local Library at 1280×720.
- Full XcodeBuildMCP build and **117 tests passed**, zero failures or skips. New tests include actual iOS Mach-O signature removal, hostile DEB paths, misleading filenames, cancellation/failure cleanup, exclusive export races, private-library integrity/link rejection, actual 5 MB HTTP streaming, ranges/HEAD, HTTPS manifests, and server restart/token rotation.
- Universal optimized app/CLI packaging, local signature verification, `scripts/check.sh --skip-build` (packaging guards and CLI smoke checks), and `git diff --check` passed. The current app is `dist/LoadSide.app`, with `dist/loadside` exposing its bundled CLI. It remains locally ad-hoc signed. Live iPhone/iPad HTTPS installation, tweak runtime behavior, Intel runtime, minimum-macOS runtime, Developer ID signing and notarization remain unverified release gates.
