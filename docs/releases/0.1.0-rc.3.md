LoadSide brings local IPA signing, saved signing identities, optional library injection, and a shared app library to your Mac.

### Install

Download the **DMG**, open it, and drag **LoadSide** to **Applications**. A ZIP is also available. Both include the command-line tool. Matching SHA-256 files are attached.

**Requires Apple Silicon and macOS 14+.** Automatic HTTPS sharing requires macOS 15+.

### Before you start

This is an **experimental prerelease**, ad-hoc signed and not notarized. See [first-launch help](../INSTALLATION.md#first-launch) if macOS blocks it. Device installation/runtime and full macOS 14 qualification remain incomplete; a verified local signature does not guarantee an app works on your device.
