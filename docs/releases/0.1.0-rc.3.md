# LoadSide 0.1.0-rc.3 — release notes draft

**Status: local evaluation candidate. No public application release is approved.**

LoadSide is a native macOS app and command-line tool for signing decrypted iOS IPA archives with your own certificate and provisioning profiles. This candidate prepares the Apple Silicon application and repository for independent evaluation.

## Highlights

- Native workspace for signing, optional library injection, saved signing identities, and clear job diagnostics.
- Local Library with browser downloads and optional HTTPS sharing. The automatic HTTPS helper requires macOS 15 or later.
- Explicit signing policies, private temporary keychains, archive validation, and verification before export.
- User guides, genuine application screenshots, contribution guidance, and automated repository checks.
- ARM64 packaging with recorded build provenance, ZIP extraction verification, checksums, and protection against overwriting existing artifacts.

See the [changelog](../../CHANGELOG.md) for the complete change list and [compatibility guide](../COMPATIBILITY.md) for policy limitations.

## Requirements and scope

- Apple Silicon Mac running macOS 14 or later. Intel and Rosetta are unsupported.
- An already decrypted IPA, a valid PKCS#12 signing identity, and appropriate provisioning profiles. LoadSide does not decrypt applications.
- Certificate and profile restrictions still apply. A successful local signature does not establish installation or runtime compatibility on an iOS device.
- Preserve original bundle identifiers and experimental main-profile reuse can produce a metadata/signing-identity mismatch. Review the visible diagnostics and qualify affected apps on a device.

## Before publication

Complete the [release qualification checklist](../RELEASING.md) for the exact source commit. Record the CI run, physical-device results, minimum-macOS and accessibility checks, Developer ID signature, accepted notarization, and an independent download test. Do not remove this status notice until those checks are complete.

A qualified production release should attach `LoadSide-0.1.0-rc.3-macOS-arm64.zip` and its `.sha256` file, identify the qualified commit, and link the sanitized qualification issue. Mark this version as a **prerelease**. Local `-local.zip` artifacts are for evaluation and must not be substituted for that download.
